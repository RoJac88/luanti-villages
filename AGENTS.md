# Agent guide

Living Villages (`living_villages`) is a Luanti mod that extends the villagers in VoxeLibre
(game id `mineclone2`, version 0.92.3). It wraps VoxeLibre's villager entity definition from
`mobs_mc` rather than replacing it. Trades, professions, and bed-ownership metadata stay in
VoxeLibre's format, so removing the mod leaves a working world with one exception: the
pulpit and the builder's bench are the mod's only nodes. Placed ones become unknown nodes and
villagers who used one as their jobsite lose it, so vanilla demotes them.

## Code map

| File | Role |
|------|------|
| `init.lua` | Entry point. Sets the villager model and textures, handles sleeping pose and waking, removes duplicate villagers, and installs the other modules into `mobs_mc:villager` |
| `cells.lua` | The one passability model (#161): which cells a villager may stand in, on and move between (`is_open`, `has_floor`, `can_stand`, `can_move`, the box checks, `has_head_room` for a villager on a bed top, `standing_position`). `common.lua`, `navigation.lua`, `fisherman.lua` and `diagnostic.lua` all ask it |
| `common.lua` | Shared helpers with no side effects: schedule stages, standing space, bed and jobsite lookups, and `work_seconds`: how much of a stretch of past game time fell in a villager's work stages, from the clock and each day's timetable. `is_holiday` honours the run-time setting `living_villages_holiday_override` (`<day>:holiday` or `<day>:work`, set by `market_test.lua`) |
| `births.lua` | Bed-limited births. The cooldown is stored in bed metadata. Automatic births need both parents fed (`food.lua`) and spend it; player-fed breeding (`on_breed`) does not |
| `child_growth.lua` | Slow child growth (#177): advances VoxeLibre's `hornytimer` by a fraction per tick so a child takes `living_villages_child_grow_days` game days, and scales the child's rendered size with its age. No catch-up while unloaded |
| `navigation.lua` | Trips to beds, jobsites, and targets. `planner.lua` chooses every route, through the route queue (#163), and `follower.lua` walks it (#164). Its `get_staticdata` wrapper also keeps a walking villager in state `gowp` across the engine's block saves, which mcl_mobs would otherwise end (#195). A `gopath` callback may be `{arrived = fn, lost = fn}`: `lost(entity, reason)` fires once when the walk ends without arriving (taken over by another mover, canceled, superseded, or no route found). A walk another mover ends on its last cell counts as arrived |
| `follower.lua` | The route follower (#164): replaces `check_gowp` for routes the planner made (flagged by `follower.begin`), and for the cleric's walk inside the church (`church.lua`, #174). Walks cell centre to cell centre, turns on the spot, cuts a corner only along a line `cells.lua` says the body fits, works doors as a step, jumps rises (vanilla's `do_jump` is off on a followed walk: it only hopped in place, #194), lands a hop down past the lower waypoint without turning back (#186), arrives on the final cell. A villager no player is within 48 nodes of is suspended by mcl_mobs and cannot move, so the follower waits for a player instead of counting that as a stall (#201). When a villager makes no progress, is pushed off the route or is blocked by another villager it ends the walk with `_villages_follow_failed` and `navigation.lua` plans again (twice at most) |
| `planner.lua` | Limited A* search over walkable positions, including stairs and wooden doors. Calls `options.checkpoint` every few nodes so a search can pause |
| `route_queue.lua` | Time-sliced planning (#162): searches (the planner, the workstation search) run as coroutines from one round-robin queue under a per-step budget (`living_villages_route_budget_ms`). A villager waits in route status `planning` and stands still. Node cap is `living_villages_route_max_nodes`; `living_villages_route_range` is the minimum search box, which `navigation.lua` grows to cover the farthest target plus 16, up to 128 (#182) |
| `doors.lua` | Which edge of its cell a door's leaf lies on, and which entries and exits of the cell that leaves free |
| `farmer.lua` | The farmer's working day. About once a second in the work stage it does the next job within reach or walks to the most pressing one: hand food to villagers, store surplus, harvest, sow, till, use bone meal, work the composter, fetch seeds or food from a chest. With the economy on it feeds itself, its household (beds within 5 of its own) and children free, sells anyone else with 64 emeralds and no food a bundle (as many as vanilla sells for one emerald, at 64, ticket 11h), gives a starving villager one item, and collects the emeralds the keeper leaves in its chest into its belongings. Every trip uses `_villages_farm_target` and `_villages_farm_route`, which navigation and the "busy" checks already know. While it has work, `activity_override` answers `farm` so vanilla's `do_work` does not call it back |
| `farm_field.lua` | What a farm is: the crops, a scan around the composter (radius 8, 2 up or down), and the writes to plots. `tillable` is the rule that keeps a field from eating the village: only beside the field (or its water, if there is no field yet), on ground water will keep wet, under `living_villages_farm_max_plots`, never a path |
| `farm_stock.lua` | The farmer's pouch (`_villages_farm_pouch`, item name to count, saved with the villager and dropped when it dies), and moving goods to and from chests already in range (`living_villages_farmer_chest_radius`), never a villager's stash (`possessions.lua`). It never places a chest. `living_villages_farmer_chest_withdraw` makes chests deposit-only. A fisherman's barrel counts as a chest for moving goods, but `find_chests` never offers one |
| `farm_compost.lua` | The composter through its hopper hooks, since its right-click handlers need a player. Marks composters a farmer filled; an ABM empties marked, unclaimed ones, since vanilla's `employ` cannot claim a filled one. Loaded at normal load for the ABM |
| `possessions.lua` | What a villager owns: belongings (`_villages_belongings`, kept apart from the work pouch, which jobs empty and drop), emeralds (3 to 6 vanilla emeralds, 192 to 384, when first seen as an adult, `_villages_endowed`; one endowed before ticket 11h has its emeralds multiplied by 64 once, `_villages_emerald_scale`), a profession kit once in its life (`_villages_kit`), and a stash: the chest nearest its bed within `living_villages_stash_radius` (8), claimed in the chest's meta (`villages_owner`, `villages_owner_bed`), never a work chest (by a jukebox, beside a composter, by a bench), passed on with the bed. `farm_stock.find_chests` leaves stashes out. Belongings drop on death. An adult never fed starts at 8 points. It eats at or below 8 points, from its belongings and then from its stash if it stands within 4 of it. `take_held` takes from belongings then stash for crafting; `same_house` is the household rule (beds within 5 across, 4 up or down). `possessions.assess` runs `ledger.assess` on what it holds (belongings and stash), its food and its trade tier, for the inspector |
| `ledger.lua` | What things are worth to one villager (ticket 3), pure. Base prices in emeralds derived from `trade_tables.lua`, times `SCALE` (64, ticket 11h: a stick is worth 2, and every emerald amount in the mod scales with it) (bought and sold prices, geometric mean where both; a hand table for logs, cobble, seeds, flowers), each profession's inputs (what it buys, plus 4 crafts of each `recipes.lua` input and coal where they smelt) and outputs (the dependency graph), and `assess`: targets from food, inputs and preferences, then needs, surplus and an urgency-weighted value per item. Charcoal and coal count together toward one target |
| `recipes.lua` | Pure data: what each crafting profession makes at its jobsite (ticket 8), each output from its trade table or an input of its own recipes (a test checks), inputs from the real crafting recipe, furnace smelts where it is smelted (and one per ingot for the smiths). The farmer, fisherman, shepherd, cleric and cartographer have none |
| `wants.lua` | Goods that wear out (ticket 11d), data plus the functions that read it: a stone hoe for farmers, axe for woodcutters, pickaxe for quarriers (by `_villages_labour`), each with its uses and rate. `targets` gives `possessions.assess` the one it should get (none in use, or `NEARLY_WORN` left) and its `worth` (uses × goods per use × the rate's gain), which caps its value in `ledger.assess`. `use` (from `farmer.lua`'s harvest and `labour.lua`'s felling and mining) takes one up from what it holds, wears it, and returns the rate the next action's wait is divided by; the one in use is in `_villages_wants`. Logs the pace every 16 uses. The tool smith makes its own sticks and planks from logs (`recipes.lua`). A book (ticket 11e) every adult wants: opened at its next work (`reading_rate`, also read by `production.lua`), it speeds work by a fifth for 3 days of game time (`_villages_wants.book.until`) |
| `demand.lua` | The economy's price terms for players (ticket 9), applied by `gossip.lua` before reputation: the trader's ledger urgency for the trade's item, square-rooted, divides what it asks when it buys and multiplies what it asks when it sells; hungry 1.25 and starving 1.5 times on what it sells. Off with the economy |
| `theft.lua` | Taking from a claimed stash (ticket 9): wraps the chests' `on_metadata_inventory_take`; awake villagers within 16 that can see the player note `minor_negative` gossip, once a minute per witness and player; what went is written in the chest's meta (`villages_missing`) and the owner finds and logs it within a minute. Off with the economy |
| `economy_tally.lua` | What a villager made and used today and yesterday (`_villages_tally`, ticket 10), noted by `production.lua` (crafts, lumps burned), `labour.lua` (gathering, charcoal) and `possessions.lua` (meals). Inspector line `Today` |
| `economy_report.lua` | A Builder's bench's economy (ticket 10), for the Economy tab and the census: shortages and gluts from the bench Builder's market news, summed by item; professions present, idle hands and the tally from loaded adult villagers within 128 of the bench (the keeper and Builder by role); gaps, professions that make what the village is short of with no producer present, worst first; `BUILDINGS`, the stock buildings holding each profession's jobsite, and `favoured`, the worst gap's |
| `need_bubble.lua` | A particle of a villager's top need (ledger needs by worth) over its head, seen only by a player looking at it within 8 nodes (a raycast once a second; a node or other object in the way hides it). Need cached 5 s. Off with the economy |
| `production.lua` | Crafting at the jobsite (ticket 8). Over work-stage economic clock time within 3 of its jobsite a crafting villager banks seconds (`_villages_craft`) and makes one craft per `living_villages_craft_seconds` (120) per item, the recipe that adds most by its own values, of those it has inputs and fuel for and holds fewer than its target plus 16 of. Inputs from belongings, then its stash wherever it is; output to belongings; fuel in smelts (`_villages_fuel`, 8 a coal or charcoal lump). Hungry works at half rate, starving not at all. A craft entirely from belongings is village supply; on `living_villages_tier_supply_days` (3) days of it at a tier (`_villages_tier_supply`) the villager goes up a tier, with `_max_tradenum` and badge updated (ticket 9). Undoes vanilla's restock on arrival at the jobsite for a starving villager, or a crafting one that can make nothing. Logs `production:` lines. A keeper or Builder crafts nothing. Off with the economy. Inspector lines `Crafting`, `Trade tier` |
| `market_news.lua` | Market news (ticket 5): who needs and who has what, passed on when a conversation runs its time. A villager's own news is its ledger's top three needs and surpluses (hops 0); hearsay is `_villages_market_news`, at most 24 entries `{item, who, kind, count, price, home, heard, hops}`. Each member tells each other up to 6, picked by the listener's interest (an item it needs offered, or has spare wanted; fresher and fewer hops; an item offered that it has heard someone needs, or wanted that it has heard someone has, counts 4 times, so news crosses villagers who do not care for the item themselves). The freshest per item, villager and kind is kept, never news of itself; news over 2 game days old is forgotten. Off with the economy. Inspector line `Market news` |
| `exchange.lua` | Trade between villagers (ticket 6), after market news when a conversation runs its time. Each pair makes at most one trade, the one that gains the two most: goods the buyer needs and the seller has spare and carries in its belongings, when the buyer values them above the seller, at the midpoint of the two values. Paid in whole emeralds (a lot the buyer cannot pay for shrinks to what its emeralds pay for; a sale under one emerald grows to make one, if the seller has spare), or in goods the seller needs and the buyer has spare, only if both gain by their own values. Logs `trade:` lines. Off with the economy |
| `trade_trips.lua` | Trade trips (ticket 11): a villager whose value for a need is at least 2 times its price plans in its putter stage a walk to a seller it heard has enough of it to make up a whole-emerald sale (`M.terms`) (`_villages_trade_trip`, legs `seller`, `chase`, `stash`, `deliver`), within 64 of its bed: buys in person from belongings (`exchange.offer` for that item), follows a loaded seller that is away from home (up to 3 walks, aimed afresh when the seller moves more than 8), or else buys from the seller's claimed stash at the midpoint of its value and the heard one, paying into the chest. It buys no more than its emeralds pay for, and with none plans no trip. A trip under way goes on in the work stage too (`activity_override` answers `putter` for it, so vanilla leaves it be) and is dropped once the day after it was planned is over. The Builder also plans in its work stage while short. Porters are hired at the end of a conversation by a member with a job, an urgent need and a delivery chest, with a purse of up to 512; they buy at the client's value and deliver goods and change, less a fee of 64. A seller that came to nothing is skipped 10 minutes; walks fail after 3 tries or 120 s, and a leg goes on once the villager stands at its end, whether or not the walk reported arriving. A trip that buys nothing in person logs why (`no trade: <reason>`). Inspector line `Trade trip` |
| `builder_market.lua` | The Builder in the market (ticket 11): while short in `requires_materials`, its missing priced materials are `_villages_builder_wants` (its ledger `extra`, so news posts them and trips buy them), bought goods move from belongings to its pouch, its purse is topped up to 512 from emeralds in its bench chests, and porters deliver to its nearest chest (`_villages_builder_drop`). Inspector line `Builder wants` |
| `rent.lua` | Rent to the Builder's bench (ticket 11b). Tenants: villagers whose bed carries `villages_landlord` (written over a finished building's footprint by `builder.lua`'s `finish_building`), and farmers and fishermen, who owe the nearest claimed bench within 128 of their bed (benches learnt from loaded Builders). Not the Builder, the keeper or its household, or children. 64 emeralds per 2 days of economic clock, owing up to 192 (the rest forgiven); paid only from emeralds above a dinner's price (18). Paid to the bench's Builder when a conversation runs its time (`init.lua`'s trade hook, before trades), or else, owing anything it can pay, by a putter-stage errand to the bench's nearest chest that is not a food chest (`possessions.is_food_chest`), paying once within 3 of it whether or not the walk reported arriving (`_villages_rent_errand`; a failed one waits a day). `_villages_rent` {owed, at, bench, paid}. Logs payments and forgiveness. Off with the economy. Inspector line `Rent` |
| `alms.lua` | Donations and alms (ticket 11c): in the holiday social stage the cleric, among the villagers within 12 of its pulpit, takes a tenth of each one's emeralds over `SAVINGS` (8 dinners) once a holiday (`_villages_donated`), keeps half and funds the rest (`_villages_alms`), then tops anyone who cannot pay for a dinner up to two (`_villages_alms_got`). Witnesses note good gossip about the donor under `gossip.villager_subject`, which `exchange.unit_price` reads as standing. Each villager there also swaps market news with the cleric once a holiday (`church_news`, `_villages_church_news`). Inspector line `Standing` |
| `herd.lua` | The leatherworker's cow herd (ticket 11e): up to 4 adult `mobs_mc:cow` marked `_villages_herder` within 32 of its jobsite, wild ones taken on, 2 seeded once (`_villages_herd_seeded`), strays set back. In the work stage every 300 s (`_villages_herd_next`) it slaughters one past 4 adults (beef and leather into belongings) or breeds a calf on 2 wheat (`mcl_mobs.spawn_child`). Inspector line `Herd` |
| `labour.lua` | Work for nitwits and the unemployed with no jobsite (ticket 7). At the first work tick of each day (`_villages_labour`) it picks forager, woodcutter, quarrier or porter (ticket 11) by the best price heard asked for their goods times their rate, yesterday's counted 1.25 times; at random among those with a site when no price is heard. A forager picks ripe sweet berries (leaving the bush), sugar cane above its bottom block and fallen apples within 32 of its bed; a woodcutter plants up to 8 saplings of any single-sapling species (oak, birch, spruce, jungle, acacia) in its grove (`_villages_grove`, open grass 8-20 from its bed, clear of paths and buildings), fells only those grown into trees and replants, and takes its first sapling from under a wild oak once a day (`_villages_sapling_day`). Goods go into belongings, up to 32 of each. A villager with no bed works from the nearest bell within 48 of where it stands at its day's choice, or from that spot (`_villages_labour_home`, `choose_home`, chosen daily). The no-work log line gives its home and how many needs and has entries it has heard. After a felling, a woodcutter burns 8 of the logs it carries past 16 into 7 charcoal, up to 32. Trips to a tree end beside its trunk; an unreachable target is skipped for 5 minutes. Logs each day's choice (or why there is none), trips and gathering. Vanilla's job claim runs first. Off with the economy. Inspector line `Labour` A quarrier mines generator cobble (lava and water both beside or above it, as VoxeLibre's Lava cooling ABM makes it) within 32 of its bed, up to 64, never terrain. A porter is open when it has heard of an item one villager needs and another has, earns what its own record says portering pays (one fee per hire per porter day, from one in two, `_villages_porter_record`; hires counted by `trade_trips.lua`), and works only on trips it is hired for (`trade_trips.lua`). A peddler (ticket 12) is open on a heard deal, an item spare at one price and needed at 1.5 times that elsewhere (`deal`); it sets `_villages_peddle` (item, count, bid, buying), buys the lot through its own trips and conversations (its ledger wants it at the bid, `possessions.assess`), then sells it at no less than the bid; `peddle_tick` moves it from buying to selling and ends it |
| `trade_tables.lua` | Generated: VoxeLibre's villager trade tables, by `tools/extract_trades/`. Do not edit by hand; `tests/trade_tables.lua` checks it against the installed VoxeLibre |
| `food.lua` | Food points (`_villages_food`; bread 4, crop 1, the tavern's prepared foods 4 to 6, the butcher's cooked meat 5 or 6, an adult wants 12), what receiving food does, and whether a villager may become a parent (`living_villages_births_need_food`). An adult's points fall by `living_villages_hunger_per_day` (4) per game day of its economic clock, worked out when read (`_villages_food_at`), never below 0; `state` is full, fed, hungry (under 4) or starving (0). Hunger never harms |
| `economy_clock.lua` | Each villager's economic clock (`_villages_econ_clock`, `_villages_econ_stamp`): game seconds it was loaded with a player in mcl_mobs' active range, stamped every 10 s; a gap of 120 s or more is skipped, so hunger (and later production) pauses while no player is near. The outermost `do_custom` wrapper. `living_villages_economy` turns the economy off. See `docs/villager-economy-design.md` |
| `tavern_pantry.lua` | The tavern's pantry: the chests within 6 of the jukebox (the stock tavern's chest is 3 behind it). Where there is one, `meal.lua` serves only what it holds, takes each plate out of it, and a player's payment goes into it |
| `keeper_supply.lua` | Keeps the pantry stocked. In its free hours, while the pantry holds fewer than 12 meals, the keeper walks to the nearest work chest with food within 48 of the jukebox (a farmer's, nearest a claimed composter, or a fisherman's claimed barrel), takes up to 24 bread, potatoes, cod and wheat into its pouch and carries them back to its jukebox, from where it fills the pantry. It pays for them with up to 512 emeralds taken from the pantry, leaving in the work chest what they sell for as dinners (one dinner's price, 18, per meal: a loaf, potato or cod is one, wheat a third; ticket 11b), owing what it cannot pay in whole emeralds in the chest's `villages_keeper_tab` (paid first next time, up to 512, the rest forgiven), and takes the food even when it cannot pay all of it (`_villages_supply_target`, an errand for `far_trips.lua`). A source it finds no way to, or stops short of, it passes over for 600 s (not saved), so the next nearest gets a turn. On shift at the jukebox it cooks one dish every 10 s (three wheat to a loaf, a potato baked, a cod cooked). Wraps `settlements.fill_chest` so a new tavern's chest gets a starting stock |
| `fisherman.lua` | The fishing loop of a fisherman with a claimed barrel, and the bobber and rod entities. With the economy on, one completed cycle in four lands a fish by `mcl_fishing`'s odds: cod into its barrel (up to 16) for the keeper, anything else into its belongings; it collects the keeper's emeralds from the barrel |
| `job_blocks.lua` | The job blocks and how each is claimed: every workstation (`common.lua`'s table, a composter at any fill level, a cauldron for a leatherworker) as vanilla's `employ` claims one, the Builder's bench, the jukebox and the pulpit through `builder.lua`'s, `keeper.lua`'s and `cleric.lua`'s own claims. `roles` (built in `init.lua`) holds those modules, the Builder added once installed. `pair` is the greedy closest-bed-and-block-first pairing |
| `job_seek.lua` | An unemployed adult (a grown child, one that lost its job) takes the free job block nearest its bed, of any kind, within `living_villages_farm_job_radius` of the bed, walks there (`navigation.seek_job`, which plans only to that block) and claims it on arrival. Meanwhile vanilla's `get_a_job` sees a traded-looking `_trades` and the block is in `_villages_farm_seek` (a saved name from when this was composters only), which `keeper.lua`, `cleric.lua` and `builder.lua` stand aside for. A block it cannot reach is passed over for 300 s. Without a bed (vanilla clears `_bed` for a while in places) it waits up to a game day, held from vanilla's search, before it looks from where it stands; a block chosen so is dropped once the bed is back |
| `village_staffing.lua` | Staffs a new village as it is placed (ticket 11f). Wraps `settlements.place_schematics` outermost, and during it `mcl_structures.place_schematic`, counting the after-placement callbacks (where VoxeLibre spawns villagers on the beds) and keeping their boxes; after the last one (or `TIMEOUT`, 120 s) it pairs the boxes' free job blocks with the new villagers by `job_blocks.pair` and claims them, leaving `living_villages_spawn_unemployed` out of work. The bench, the jukebox and the composter nearest any new bed are paired first, so a village gets its Builder, its keeper and a farmer. A villager not yet loaded (a village generated at the edge of what is loaded) is paired by its bed's meta id: its block's meta holds its id and mod storage (`staffing:<id>`) the rest, finished by `apply_pending` when it loads. Until then `install_villager` keeps those villagers out of every job module. Logs `staffed a new village: ...` |
| `nitwit.lua` | Keeps nitwits from being demoted to unemployed by VoxeLibre's jobsite check |
| `keeper.lua` | Tavern keeper role, which is a butcher underneath and claims a jukebox, plus its menu and hours |
| `music.lua` | On holidays the keeper on duty plays the jukebox's disc (or the day's default record when it holds none) from dinner to close, started per player in hearing range (#187) |
| `tavern.lua` | The evening tavern visit and keeper takeover |
| `far_trips.lua` | Hides the bed from vanilla's `wandered_too_far` test (#216) while a villager has an errand (claimed jobsite at work, tavern, church, social, bell, the morning bell (#329), a trade trip or rent errand in any stage) more than 50 nodes from home; `init.lua` runs vanilla's `do_custom` through it |
| `wander.lua` | Replaces vanilla's aimless walk with short, checked straight legs that stop short of walls |
| `seat.lua` | Chair reservation and the sitting pose, for dinner tables and church pews |
| `meal.lua` | Serving and eating dinner on plates, and the `living_villages:meal` display entity; also serves player diners (#19). With a pantry (`tavern_pantry.lua`) the meal comes out of it, feeds a villager guest when served, and the diner pays first: a player its price, a villager 18 emeralds (`ledger.DINNER`) from its belongings (the keeper's household free), and a villager is served only at or below 8 points; each villager's payment is logged (ticket 11b); without one it is a display, as before. Once an evening a seated villager swaps market news with the keeper on duty (`tavern_news`, `_villages_tavern_news`), so the keeper relays needs and supply between diners |
| `player_meals.lua` | Players eat in taverns (#19): a player sitting (found by watching `mcl_cozy.players`, since mcl_decor chairs hold `mcl_cozy.sit` by value) on a chair at a table within a tavern whose keeper is on duty is served through `meal.lua`'s loop as a diner table. Each bite feeds through `mcl_hunger` (3 hunger, 1.5 saturation per meal, none when full); one meal per player per tavern per game day, in memory. In a tavern with a pantry the meal comes out of it and costs `living_villages_player_meal_price` emeralds (unset: 18 with the economy on, 1 off), paid into the pantry; free without one. `living_villages_player_meals` turns it off. Logs one `[living_villages] player meal` line per change of state (why it does or does not serve), and `/living_villages_meal` (server priv) says the same for the chair you sit on |
| `tavern_schematic.lua` | Furnishes newly generated taverns by editing the stock schematic in memory |
| `cleric.lua` | Clerics claim free pulpits through the same node metadata vanilla uses and work there |
| `pulpit.lua` | The `living_villages:pulpit` node, a lectern clone that is no profession's jobsite |
| `church.lua` | The holiday church service: villagers take pews or stand at the back, and the cleric stands at the pulpit. The social stage after it (#327) keeps them about the church in anchored `wander.lua` legs within 12 nodes of the pulpit |
| `bell.lua` | The holiday bell gathering: eligible traders open market stalls through the shared seller controller; browsers walk to the bell and drift about it in anchored `wander.lua` legs within 14 nodes |
| `market_site.lua` | Market stall layout, bounded site search (144 candidates 4-12 from the bell's floor, 3 above and below it), and expiring reservations shared by sellers; `reasons(search)` counts why candidates were turned down, logged with `no stall site found` |
| `market_test.lua` | `/living_villages_market open \| work \| clear` (server priv), for testing by hand: `open` makes today a holiday at the start of the bell stage and lets every loaded villager set up a stall again; `work` makes it a working day at the start of the work stage, has nitwits and the unemployed choose work again, and replies with the news each has heard and its best peddling deal; `clear` drops the override |
| `market_props.lua` | Places, tags, leases, packs, and recovers ordinary table and item-frame stall props; loaded once at normal mod load |
| `market.lua` | Profession goods and the seller session controller used by `bell.lua`; saves only the per-day stock guard and keeps live routes/leases transient. With the economy on it uses `market_stall.lua` (`use_economy`) for a stall's goods, its banner and its sales |

## Testing

```sh
for t in tests/*.lua; do lua5.1 "$t"; done   # CI uses Lua 5.1; any newer lua also runs them
```

Each test file stubs the parts of `minetest`/`core` that it needs and `dofile`s the module under
test. Add or extend the matching test when you change behavior. CI
(`.github/workflows/lua-tests.yml`) runs a syntax check on every `*.lua` file and then runs
every test.

## Conventions

- Target the Lua 5.1 / LuaJIT language level. Indent with tabs. Each file starts with
  `local core = minetest`.
- Load modules with `dofile(core.get_modpath("living_villages") .. "/x.lua")`. Entity
  registrations, including those in `fisherman.lua` and `meal.lua`, have to run during the mod's
  normal load, not inside `register_on_mods_loaded`. This is because `register_entity` checks
  the current mod name.
- Registered names such as entities, formspecs, and LBMs, along with media file names, use the
  `living_villages` prefix. Log lines start with `[living_villages]`.
- Composter fill levels are separate nodes, swapped in with their metadata. Use `common.is_composter_node`, not the empty node's name, for a farmer's jobsite, and `swap_node`, not `set_node`, on one, which would wipe the claim.
- Food must not go through the ground: vanilla's pickup treats it as breeding input, and matches `potato_item` against baked and poison potatoes too.
- **Don't rename saved state.** The `_villages_*` fields on villager entities and the
  `villages_last_birth` bed metadata key are saved in players' worlds. They kept their old names
  when the mod was renamed, and renaming them now would silently reset those villagers.
- Header comments explain why a module exists and refer to GitHub issues as `#NN`. Keep
  comments about as dense as the code around them.
- Work out visual constants such as poses, offsets, and attachment points from the model and
